# My Story — A robust role-based access control (RBAC) application.

This project showcases a complete full-stack web application featuring a robust Role-Based Access Control (RBAC) system. It demonstrates secure authentication, authorization, and a responsive modern user interface to manage users and permissions effectively.

## Key Features

- **Role-Based Access Control (RBAC)**
  - Strict enforcement of user roles for protected resources and actions.
- **Secure Authentication**
  - Robust user login and registration system using JSON Web Tokens (JWT).
- **Modern User Interface**
  - Clean, responsive, and accessible UI built with Next.js and Tailwind CSS.
- **Modular Architecture**
  - Separation of concerns with dedicated frontend and backend codebases.
- **Form Validation**
  - Client and server-side schema validation using Zod.

## Technology Used

- **Frontend**: Next.js, React.js, Tailwind CSS, shadcn/ui
- **Backend**: Node.js, Express.js, MongoDB, JWT
- **Deployment**: Local Environment
